# Super U requests (captured on the site, 2026)

Reference pages: `test/fixtures/superu/` (regenerated by `npm run fixtures -- superu`).

Every request goes through the user's browser session (`credentials: include`).
No anti-bot protection is bypassed: the server replays the calls the site makes on a click.

## Search

- `GET /recherche?q=<term>`: server-rendered HTML page.
- Products: `.product-tile` (excluding `mini-cart`), identifier in `[data-pid]`, name in `.product-name`,
  price as `.sr-only` text "X euros Y centimes", unit price `.unit-info` "X,YY €/kg|l|pce".
- A tile with a multibuy promotion holds a second `.unit-info` inside `.promo-price` ("3,05 €/l les 2"):
  that is the bundle price; the single item's price is read instead.
- `input[name="csrf_token"]` token present on the page.
- Availability: text "indisponible", "rupture de stock" or "Bientôt disponible".
- Promotion: `.promotion-title-one` ("Promotion", "Avantage Carte U"), validity "jusqu'au JJ/MM",
  details in `.promotion-tooltip-first` / `.promotion-tooltip-second`, struck-through price "X euros Y au lieu de …".

## Product page

- `GET /p/<label>/<id>.html`: the site ignores the label, only the identifier matters (`/p/produit/3870987.html`).
  Unknown identifier: HTTP 410.
- Name: `h1`. `#product-details` block: "Composition et origine" tabs, each heading an `h3.tab-label`, followed by
  the content in the next `li`.
  - "Ingrédients": full text, allergens in capitals, traces at the end of the list. Some pages repeat the
    "Ingrédients :" prefix.
  - "Origine": the page's statement ("Né, élevé et abattu en France"), mostly on raw products.
  - A raw product (fruit, fresh meat) has no ingredients.

## Add / remove

- `POST /on/demandware.store/Sites-DigitalU-Site/fr_FR/Cart-AddProduct?format=ajax`
- `Content-Type: application/x-www-form-urlencoded; charset=UTF-8`, `X-Requested-With: XMLHttpRequest`
- Fields: `pid`, `Quantity`, `quantity`, `update=true`, `modifiableOrderID`, `fullview`, `location=search`,
  `requestedQuantity`, `isLuckyProduct=false`, `pageId`, `pageType`, `operationId`, `sponsoringType`,
  `sponsoringCampaignId`, `csrf_token`.
- **This POST sets the quantity** (checked: 1, then 1 → 1; 3 → 3). Cumulative addition therefore reads the cart
  and sends `current quantity + n`.
- Removal: same endpoint with `Quantity=0`.

## Reading the cart

- `GET /panier`: `li.cart-row` lines with `input[name="pid"]`, `input[name="Quantity"]`, name in
  `[class*="product-name"]`, line total as `.sr-only` "X euros Y centimes", unit price in `.unit-info`.
- `.notavailable` ("Bientôt disponible") appears on **every** line, hidden with CSS: it is not an availability
  signal, so it is not read. Availability is read on the search tiles.
- Estimated total: `.order-total-estimate`.

## Order conditions (read-only)

- `GET /on/demandware.store/Sites-DigitalU-Site/fr_FR/Home-IncludeNavigationSlotTimeInfo`: header banner.
  - `[data-footer-slots-info]`: JSON (HTML entities) `{"drive":{"slotText","slotAvailable","slotFull"},"delivery":{…}}`,
    next slot offered per mode.
  - `.cu-shipping-methods-store`: retailer and store name ("super u", "<store name>").
  - `[data-store-description-delivery]`: booked slot ("Dim. 25/10 de 08h30 à 09h00") or "Choisir un créneau".
- `GET /panier`, `.cart-minimum-order-amount-block`: `.cart-minimum-amount` "Retrait drive : 50 €",
  "Livraison à domicile : 50 €".
- The full slot grid (`DeliverySlot-GetDeliverySlotsStore`, `DeliverySlot-GetDeliverySlotsWeb`) needs pickup point
  parameters that were not captured: not used. `Checkout-SetBookingSlot` books a slot: **never called**.

- Expired session: handled as `SessionExpiredError`.
